# Данные

Синтетические графы генерируются кодом и не хранятся.

## Водопроводные сети

- `data/wdn/manifest.csv` — список сетей, источник, SHA-256 файла `.inp` и статистика предобработки. **Заполняется до расчёта любых признаков** (протокол предобработки, §0).
- `data/wdn/raw/` — сами файлы `.inp`; в git не попадают (см. `.gitignore`), воспроизводимость — через источник и SHA-256.
- В НИР-2 по этим сетям считаются только признаки X, без R.
