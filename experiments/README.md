# Эксперименты

Один эксперимент — один скрипт; параметры и seeds — в `configs/`, результаты — в `results/`.

| Скрипт | Что | Когда |
|---|---|---|
| `first_robustness_curve.py` | Первая кривая S(p) и R на ER со сверкой с теорией | фаза I |
| `e_rep.py` | Выбор представления box-covering без R | фаза V – ноябрь |
| `e_mf.py` | R против R_MF по семействам и вдоль траекторий перестройки | фаза V – ноябрь |
| `wdn_profiles.py` | Структурные профили ВРС, сравнение с ансамблями, покрытие | фаза V |
| `e_dim.py` | Лестница M0 → M3, режимы I и II | декабрь |
| `e_ews.py` | Динамика (H-ews) | НИР-3 |
