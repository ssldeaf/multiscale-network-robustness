# multiscale-network-robustness

Код ВКР «Разработка метода раннего прогнозирования структурной устойчивости инженерных сетей по динамике топологических и фрактальных характеристик при последовательных отказах элементов с применением машинного обучения» (НИТУ МИСИС, прикладная математика).

**Вопрос НИР-2 (H-dim).** Объясняет ли многомасштабная (box-covering) структура сети отклонение её устойчивости к случайным отказам от перколяционного прогноза по распределению степеней — сверх степеней, локальных мотивов и прокси масштаба?

## Определения

| Величина | Определение |
|---|---|
| S_t | \|LCC(G_t)\| / n₀ после удаления t вершин в случайном порядке, t = 0…n |
| R | (1/n)·Σ_{t=1..n} S_t — t = 0 не входит |
| R̄ (target) | среднее R по 30 порядкам удаления |
| R_MF | тот же расчёт для S_MF(φ) = φ·[1 − G₀(u)], u = 1 − φ + φ·G₁(u) — прогноз по распределению степеней |
| ΔR | R̄ − R_MF |

R_MF — асимптотический прогноз для локально древовидных графов, а не точная теория. log n / log⟨ℓ⟩ — прокси масштаба, а не размерность.

## Установка и запуск

Windows (PowerShell):

```
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
pytest
```

Если PowerShell не даёт активировать окружение: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.
Linux / macOS: `source .venv/bin/activate`.

Сразу после создания репозитория тесты падают с `NotImplementedError` — так и задумано: реализуй функции в `src/netres/robustness/simulation.py`, пока `pytest` не станет зелёным. Затем:

```
python experiments/first_robustness_curve.py
```

Ожидаемо для ER (n = 1000, ⟨k⟩ = 4): R ≈ 0,40; рисунок — `results/first_curve.png`.

## Правила кода

1. Сначала алгоритм на бумаге, потом код. У каждой функции docstring: что считает, формула, сложность.
2. Входной граф не изменяется: траектории повреждения строятся на копии.
3. Случайность — только через `seed` / `np.random.default_rng`; никакого глобального состояния.
4. Тесты на маленьких графах с ответом, посчитанным руками; своя реализация сверяется с NetworkX.
5. Быстрая версия алгоритма тестируется на точное совпадение с медленной (Ньюман–Зифф против наивной симуляции).
6. Реальные водопроводные сети в НИР-2 — только признаки X, без R (внешний тест НИР-3).
